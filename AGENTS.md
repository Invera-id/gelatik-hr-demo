# Project Instructions

This repository is a demo prototype for PT Gelatik Supra.

Read these files before modifying code:
- docs/DEMO_SPEC.md
- docs/DEMO_PROGRESS.md

Rules:
- This is a frontend-only demo.
- Do not add backend services.
- Do not add external APIs.
- Do not use actual Gelatik employee data.
- Use dummy data only.
- Avoid overengineering.
- Keep business logic isolated in reusable functions.
- Run lint/build after significant changes.
- Update docs/DEMO_PROGRESS.md after completing a phase.
